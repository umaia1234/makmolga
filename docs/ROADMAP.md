# 맠몰가의 다음 단계

**마인크래프트 완전몰입형 가상현실**은 장기 방향입니다. 현재 저장소는 그 출발점인 캐릭터 선택과 LLM 동료 제어를 다룹니다. 아래 예정 항목은 구현 완료나 출시 일정에 대한 약속이 아닙니다.

| 단계 | 상태 | 완료 기준 |
|---|---|---|
| 캐릭터를 만나는 입구 | v0.2 구현·로컬 검증 | 다섯 스킨, 성격 툴팁, 월드별 선택, 게임과 실행기의 선택 동기화 |
| 실제 서버의 동료 | 다음 검증 | 별도 계정 접속, 소유자 채팅, 실제 LLM 응답, 이동·중지·상자·한 칸 농사 결과 확인 |
| 캐릭터가 이어지는 대화 | 예정 | 선택한 성격의 응답 일관성, 재접속 후 문맥, 사용자의 수정·중지 지시 준수 |
| 기지에서 함께 생활 | 예정 | 재료와 좌표를 확인한 건축·농사·창고 정리, 실패 시 복구, 장시간 운용 기록 |
| 함께 보이는 캐릭터 | 예정 | 봇 계정 또는 명시된 클라이언트/서버 외형 연동, 다른 플레이어에게 보이는 모습 검증 |
| 몰입 인터페이스 | 연구 전 | 음성·VR 입력·시점·상호작용의 범위와 기술 선택, 별도의 실제 기기 테스트 |

현재에는 신체 감각 입출력, 뇌 인터페이스 또는 완전몰입 VR 기능이 없습니다. 테스트 통과, 시각적 미리보기, 실제 서버 플레이와 실제 기기 체험의 증거를 서로 구분해 기록합니다.
