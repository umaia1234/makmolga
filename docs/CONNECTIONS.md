# 젬짱·클짱·페짱 자동 연결

**v0.4.0-alpha.2 설치판에는 일곱 캐릭터가 모두 포함됩니다.** 처음 쓰시는 분은 [시작 안내](../START-HERE.md)를 따라 주세요. 아래 문서는 캐릭터별 공급자 연결 참고입니다. 첫 연결은 모든 친구가 Codex를 사용하며, 캐릭터별 서비스 선택을 저장하면 다른 공급자를 사용합니다.

맠몰가 폴더의 **`Connect-Companions.ps1`**을 실행하면 한국어 동료 연결 센터가 열립니다. PowerShell에서는 `./Connect-Companions.ps1`, 터미널에서는 `npm run connections`로 열 수 있습니다. 이 화면은 이 PC에서만 실행되며 브라우저를 닫아도 게임 실행기의 동작에는 영향을 주지 않습니다.

게임 모드를 업데이트했다면 **H → 연결 설정 → 동료 자동 연결 센터 열기**에서도 열 수 있습니다. 처음에는 같은 화면의 폴더 칸에 맠몰가 프로젝트 폴더를 넣습니다. 스크립트를 지원하지 않는 PC에서는 터미널에서 `npm run connections`를 사용합니다.

## 처음 한 번

1. 여러 서비스를 함께 쓰려면 **기본 캐릭터 조합 자동 설정**을 누릅니다. 젬짱에 Antigravity, 클짱·페짱에 Claude Code, 나머지 친구에 Codex를 연결하는 조합입니다. 필요한 프로그램을 찾아 재사용하고, 없는 프로그램은 공식 Windows 설치 프로그램으로 설치합니다. Codex 하나만 사용하실 경우 이 단계는 건너뛰어도 됩니다. 게임 도구 연결과 캐릭터별 기본 조합을 저장하며 기존 서버·소유자·접두어·안전 설정은 유지합니다. 소유자 UUID가 이미 설정되어 있으면 LLM 컨트롤러를 켭니다.
2. **로그인 필요**가 표시되면 해당 서비스 카드의 **계정 로그인**을 누릅니다. 기본 브라우저의 공식 페이지에서 직접 로그인합니다. Antigravity 페이지에 인증 코드가 나오면 연결 센터의 인증 코드 칸에 붙여넣습니다. 공식 CLI의 인증 제한 시간은 현재 60초이며 남은 시간을 표시합니다. 코드는 로그인 프로세스에만 전달하고 연결 센터 파일에 저장하지 않습니다. 코드가 만료되면 계정 로그인을 다시 누릅니다. **다시 확인**은 인증 창을 열지 않습니다.
3. 아래 캐릭터 행의 **연결 시험**을 누릅니다. 계정의 모델 사용량으로 작은 실제 요청을 보내고, 시험용 게임 상태 도구가 반환한 값을 모델이 읽었는지 확인합니다. 성공하면 **확인됨**으로 바뀝니다. 이 시험은 플레이 중인 월드를 움직이거나 채팅을 보내지 않습니다.
4. 모델을 바꿨다면 **설정 저장**, 이미 맠몰가가 실행 중이면 **실행 중인 동료에 적용**을 누릅니다. 답변 도중에는 현재 답변이 끝난 뒤 적용하라는 안내가 나옵니다. 게임 실행기를 처음 켤 때는 `./Start-Makmolga.ps1`을 사용합니다.
5. Minecraft **H**에서 친구를 선택합니다. 이후 소유자의 게임 채팅과 자율 모드는 그 캐릭터에 연결된 LLM으로 전달됩니다.

아직 Minecraft 서버·봇 계정·소유자 UUID를 설정하지 않은 새 설치라면 [시작 안내](../START-HERE.md)부터 완료해 주세요. AI 계정 로그인만으로 마인크래프트 계정이나 서버가 생기지는 않습니다. 멈춤·사망 상태인 봇은 연결 설정 적용으로 자동 재개되지 않습니다.

| 친구 | 기본 서비스 | 기본 모델 |
|---|---|---|
| 젬짱 | Antigravity CLI | Antigravity 계정의 기본 모델 |
| 클짱(클로드짱) | Claude Code | `opus` |
| 페짱(페이블짱) | Claude Code | `fable` |
| 지피짱·얀로롱·도로롱·스피키 | Codex App Server | 기존 Codex 모델 설정 |

젬짱을 반드시 Gemini로 사용하려면 Antigravity에서 선택된 모델이 Gemini인지 확인하거나, 해당 행에 계정에서 사용할 수 있는 정확한 Gemini 모델 이름을 지정합니다. 공식 `agy models` 명령으로 목록을 확인할 수 있습니다. 서비스와 모델은 모든 캐릭터에서 직접 바꿀 수 있습니다. 빈 모델 칸은 해당 프로그램의 기본 모델을 따릅니다. 사용할 수 없는 모델을 다른 서비스로 몰래 바꾸지는 않습니다.

## 다음부터

평소처럼 `./Start-Makmolga.ps1` 또는 설치된 시작 스킬을 사용합니다. 일곱 친구는 한 봇의 선택 가능한 캐릭터이며 동시에 일곱 봇이 접속하는 기능은 아닙니다. 클짱·페짱의 대화 세션은 캐릭터·공급자·모델별로 분리됩니다. 기존 Codex 캐릭터 대화는 유지합니다.

Claude와 Antigravity가 답하는 중에 새 일반 채팅이 오면 대기열에 남겨 다음 턴으로 전달합니다. 물리 작업을 자동으로 취소하지 않습니다. “멈춰”는 게임 동작과 진행 중인 CLI 턴을 중지합니다. 전송 직후 실행기가 끊기는 등 결과가 불확실하면 `uncertain`으로 남기고 같은 작업을 자동 재전송하지 않습니다.

Claude는 기존 여섯 방향 카메라 이미지를 받을 수 있습니다. 현재 Antigravity CLI의 스트림 입력은 텍스트만 지원하므로 좌표·블록·인벤토리 관찰을 사용합니다. 이미지가 전달되지 않았음을 모델에 명시합니다.

## 저장 위치와 복구

- `config.local.json`: 캐릭터별 서비스·모델, 설치된 실행 파일의 위치. 기존 파일을 변경하기 전에 같은 폴더에 `.makmolga-날짜-ID.bak` 백업을 만듭니다.
- `.mcp.json`: 이 프로젝트의 Claude Code 게임 도구 등록.
- `.agents/mcp_config.json`: 이 프로젝트의 Antigravity 게임 도구 등록.
- `~/.gemini/antigravity-cli/settings.json`: Antigravity를 사용하는 기본 조합을 자동 설정할 때 `mcp(makmolga/*)` 허용을 추가합니다. 다른 도구의 허용·거절·확인 설정은 유지합니다.
- `runtime/connection-checks.json`: 실제 연결 시험의 공급자·모델·확인 시각.
- `runtime/providers/`: 게임 대화 전용 작업 디렉터리. 매 턴의 게임 도구 연결은 별도 임시 권한을 사용하며 턴 종료와 중지 즉시 폐기됩니다. 호스트 명령·파일 편집 도구가 노출되면 실행을 중단합니다.

손상된 JSON을 발견하면 덮어쓰지 않고 오류를 표시합니다. 문제가 있으면 실행기를 종료한 뒤 원하는 `.bak` 파일을 원래 이름으로 복원합니다. 다른 MCP 서버나 사용자 계정 인증 파일을 삭제하지 마세요. `runtime`에는 개인 대화와 로컬 연결 정보가 있으므로 공개 저장소에 올리지 않습니다.

## 이번 PC에서 확인한 범위 (2026-09-07)

Claude Code **2.1.220**에서 `opus`, `fable` 모델의 실제 응답과 게임 상태 도구 왕복을 연결 센터에서 확인했습니다. Fable은 실제 `claude-fable-5`로 응답했고, 실행기를 다시 만들어 직전 대화의 도구 결과를 기억하는 것도 확인했습니다. Antigravity **1.1.27**은 공식 설치·실행·로그인 필요 상태까지 확인했고, 실제 모델·게임 도구 시험은 Google 로그인 이후에 가능합니다. 새 어댑터의 중지·대기열·권한·불확실 전달은 별도 자식 프로세스 시험으로 검증했습니다. 이것을 Antigravity 실계정 검증으로 간주하지 않습니다. Node 회귀 시험 71개와 Fabric 빌드·JUnit 11개를 통과했습니다.
