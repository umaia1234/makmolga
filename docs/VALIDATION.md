## 자동 테스트의 내용

- 잘못된 설정/행동 인자 거부와 안전한 기본값.
- 소유자 UUID와 일반 플레이어 채팅 원문 검사. 위조 표시 이름, 다른 UUID, 시스템/서명 불충족 메시지 거부.
- Minecraft와 Codex 입력의 동일 owner/role, 고유 ID 중복 제거.
- 재시작 시 중간 작업과 불확실한 메시지 전달 상태 보존.
- 이동 시간 제한, 동시 작업 거부, 즉시 중지 후 입력 해제.
- 저산소 대응, 임계 체력 접속 종료.
- 취소를 따르지 않는 작업의 독점 유지와 접속 종료 요청.
- 씨앗 없는 수확 금지, 재파종 확인, 기존 블록 덮어쓰기 방지.
- 부분 입출고 수량 차이를 실패로 보고, 인챈트 예산 초과 시 소비 전 차단.
- HTTP 토큰/Origin 검사와 작업 결과 조회.
- 실제 MCP stdio 클라이언트의 도구 13개 발견, 상태 조회, 작업 시작·취소.
- 실제 실행기 프로세스의 시작, 중복 실행 방지, 인증된 종료.
- 모의 App Server를 통한 원문 사용자 입력/같은 대화 ID/활성 턴 steer, 불확실 전달 미재시도, 동적 도구 입력 검사, 응답 중복 중계 방지.
- 실제 Mineflayer의 로컬 패킷 서버 로그인, 청크 읽기, 물리 이동과 채팅 송신.
- 실제 ViaProxy 두 개를 이용한 **protocol 775 → 776 → 775** 왕복. TCP 구간에서 776 핸드셰이크를 관측하고, 청크 수신·이동·채팅 도착을 확인.

처음 변환 경로 테스트에서는 테스트 서버가 `select_known_packs`를 보내지 않아 설정 단계에서 대기했습니다. 해당 패킷을 로컬 테스트 서버에 추가한 후 정상 통과했습니다. 실제 런타임에서 번역 오류를 무시하거나 버전 검사를 우회하지 않았습니다.

## 아직 검증하지 않은 것

1. **실제 Java 26.2 서버에서의 플레이:** 계정 인증, 서버 규칙, 새 콘텐츠, 실제 상자/인챈트의 패킷과 월드 결과.
2. **장시간 생존/기지 운영:** 30분 탐험 동안 독립 농사·창고 운영이나 무인 생존 성공을 증명하지 않았습니다.
3. **실제 모델 컨트롤러:** Codex 초기화와 모의 프로토콜 검사는 통과했지만, 로그인된 모델의 도구 선택·장기 판단·동시 CLI 채팅을 종단 검증하지 않았습니다.
4. **현재 Windows Desktop 대화의 자동 사용자 말풍선 삽입:** 제공하지 않습니다. MCP 메시지함 읽기 또는 같은 App Server/대화 ID를 공유하는 컨트롤러 방식을 제공합니다.
5. **26.2 새 콘텐츠 전체의 네이티브 의미:** Mineflayer는 26.1 데이터를 사용하며 ViaProxy가 새 콘텐츠를 매핑할 수 있습니다.
