# 맠몰가의 데이터와 AI 사용량

확인 기준: v0.4.0-alpha.1 소스, 2026-09-07.

## 선택한 AI로 보내는 정보

설정한 소유자의 게임 채팅, 캐릭터 성격과 대화 문맥, 좌표·체력·인벤토리·주변 블록 같은 게임 관찰을 선택한 AI 실행기로 전달합니다. **동료 시야 이미지 전달**을 켜면 Minecraft 클라이언트가 촬영한 게임 이미지도 전달합니다. 주변 플레이어 이름이나 게임 채팅처럼 관찰에 포함된 정보가 함께 들어갈 수 있습니다.

Codex·Claude Code·Antigravity는 각 서비스의 계정과 이용 정책을 사용합니다. 사용자 대화와 연결 시험도 계정의 사용량을 쓰며, 먼저 말하고 행동하기를 켜면 별도의 배경 호출이 생깁니다. 기본 배경 호출 상한은 시간당 24회입니다. Antigravity의 현재 어댑터는 텍스트 관찰만 전달합니다.

## 이 PC에 남는 정보

- `config.local.json`: 서버 주소, 소유자 게임 이름·UUID, AI 실행 파일 위치, 게임 설정.
- `runtime`: 대화·작업·이벤트·캐릭터별 세션, 로컬 API 연결 정보, 계정 연결 시험 결과, 백업, 게임 연결 프로그램의 인증 캐시.
- 각 AI 공식 프로그램의 계정 파일: 해당 프로그램이 관리합니다. 입력한 Antigravity 인증 코드는 로그인 자식 프로세스로 전달하며 맠몰가 파일에 저장하지 않습니다.

준비 화면과 게임 제어 API는 `127.0.0.1`에 연결하며 로컬 토큰을 검사합니다. 게임 소유자 확인은 UUID를 사용합니다. AI에 제공하는 도구는 게임용이며, PC 명령 실행·임의 파일 편집 도구가 CLI 초기화에서 노출되면 해당 턴을 중지합니다.

## 설치 중 접속하는 곳

필요한 구성요소는 Node.js, npm, Fabric, Adoptium, ViaProxy와 각 AI의 공식 배포처에서 받습니다. 이름 확인은 Mojang 프로필 조회에 입력한 게임 이름을 보냅니다. 서버 응답 확인과 함께 시작은 설정한 Minecraft 서버에 접속합니다. 실행 환경 다운로드의 버전과 SHA-256은 `resources/downloads.json`과 `src/proxy.mjs`에 기록합니다. Codex는 버전을 고정한 npm 패키지로 설치하며, 선택 설치하는 Claude·Antigravity는 공식 설치 프로그램을 사용합니다.

문제 보고에 `config.local.json`, `runtime`, `.mcp.json`, 인증 코드나 계정 파일을 첨부하지 마세요. 오류를 공유할 때에는 서버 주소·사용자 이름·대화 내용도 직접 확인해 주세요. 동료를 완전히 끄려면 준비 화면의 **실행기 종료**를 사용합니다.
