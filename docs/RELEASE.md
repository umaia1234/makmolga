# v0.4.0-alpha.2 검증 기록

검증일: 2026-09-07. Windows x64 · Minecraft Java 26.2 · Fabric Loader 0.19.5.

## 캐릭터 복원

alpha.1 패키징에서 제외됐던 **얀로롱·지피짱·도로롱·젬짱·스피키**를 복원했습니다. 설치 ZIP과 모드 JAR에 기존 다섯 명과 **클짱·페짱**, 일곱 캐릭터의 스킨·성격·선택 정보를 함께 넣습니다. 새 캐릭터를 다시 만들거나 기존 스킨과 말투를 바꾼 것이 아니라 원본 파일을 그대로 포함하는 수정입니다.

ZIP 패키저와 Fabric 빌드의 캐릭터 필터를 제거했습니다. 새 `standard` 설치판의 검증기는 일곱 ID를 모두 요구하며, ZIP 카탈로그와 JAR 카탈로그의 모든 필드, 각 스킨의 실제 JAR 내부 SHA-256, 설치 폴더의 스킨·성격 파일을 확인합니다. 이전 alpha.1 파일의 검증도 유지합니다.

## 이번 수정에서 다시 실행한 검사

- Node 문법 검사: 58개 모듈 통과.
- Node 회귀 시험: **81개 통과**, 실패·건너뜀 0. 원본 일곱 스킨과 카탈로그 해시, 캐릭터 선택·대화 기록·일반 채팅 중 작업 유지·설치 백업과 복구를 포함합니다.
- Fabric JAR 재빌드 및 **JUnit 12개 통과**, 실패 0. 실행 명령은 `./Build-Mod.ps1`입니다.
- 포장된 일곱 캐릭터의 실제 성격 문서를 모두 불러왔고, 준비 화면에서 7명과 각 서비스·모델 입력 행이 표시되는 것을 확인했습니다.
- 시험용 Minecraft 폴더에서 실제 alpha.1 JAR을 alpha.2로 교체했습니다. 새 JAR의 7인 구성과 파일 해시, 이전 JAR의 정확한 백업, 기존 도로롱 월드 선택과 다른 모드 보존을 확인했습니다. 게임 클라이언트나 실제 월드는 실행하지 않았습니다.
- 패키징 명령 `npm run release:package`는 완성 ZIP을 다시 풀어 파일 허용 목록·필수 파일·버전·체크섬과 7인 구성을 검사합니다. 게시된 ZIP/JAR의 실제 다운로드 대조 결과는 [릴리스 본문](https://github.com/umaia1234/makmolga/releases/tag/v0.4.0-alpha.2)에 기록합니다.

## 이전 설치·AI 연결 검증

이번 수정은 캐릭터 포장과 검증·안내 문서를 바꿉니다. Node/Java/Fabric/ViaProxy의 공식 다운로드와 설치·백업·복구, 실제 Codex/Claude 모델의 시험용 게임 도구 왕복은 [alpha.1 검증 기록](RELEASE-v040-alpha1.md)에서 확인할 수 있습니다. 그 기록의 2인 패키지 설명과 시점은 당시 결과이며, 현재 설치판의 캐릭터 수는 일곱 명입니다.

## 설치와 업데이트

처음 설치하거나 alpha.1을 받으신 경우 [시작 안내](../START-HERE.md)를 따라 주세요. 새 ZIP을 새 폴더에 풀고, 이전 실행기를 종료한 뒤 `config.local.json`과 `runtime`을 복사하고 새 준비 화면에서 **게임에 모드 설치**를 다시 누릅니다. 게임을 다시 시작한 뒤 **H**에서 일곱 캐릭터를 선택할 수 있습니다. 이전 폴더는 복구용으로 보관해 주세요.

## 남아 있는 검증 범위

일반 온라인 봇 계정의 첫 접속, 다양한 PC·런처, 모든 작업의 실제 월드 결과, 장시간 자율 생존은 추가 검증이 필요합니다. Antigravity의 실계정 모델·MCP 확인도 남아 있습니다. 이번 캐릭터 복원을 실제 게임 전체의 품질 보장으로 해석하지 않습니다.
