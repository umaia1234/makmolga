# v0.4.0-alpha.1 검증 기록

검증일: 2026-09-07. Windows x64 · Minecraft Java 26.2 · Fabric Loader 0.19.5. 공개 설치 ZIP과 JAR은 자체 제작 클짱·페짱을 포함합니다.

## 자동검사

- Node 문법 검사: 실행기 모듈 58개와 준비 화면 JavaScript 통과.
- Node 시험: 전체 회귀 **81개 통과**. 실패·건너뜀 없음. 미로그인 Codex를 로그인 완료로 오판하지 않는 회귀 시험도 포함합니다.
- Java 공개판 빌드: 실제 컴파일·JUnit 12개 통과, 실패 없음. 공개판에 없는 월드 선택을 다시 고를 수 있도록 검사합니다.
- 실제 Mineflayer 접속·청크 수신·이동·채팅 패킷과 ViaProxy 775 → 776 → 775 왕복을 확인했습니다. 이는 시험용 프로토콜 서버 결과이며 vanilla 26.2 전체 플레이 검증은 아닙니다.
- 인증·호스트 경계, 명시적 중지, 일반 채팅 중 작업 유지, 불확실한 전송의 재실행 방지, 캐릭터별 대화 보존을 검사합니다.

실행 명령: `npm run check`, `npm test`, `./Build-Mod.ps1 -OriginalEdition`.

## 새 설치 리허설

개발 맥락 없이 ZIP과 안내 문서만 받은 독립 실행자가 별도의 임시 폴더에서 실제 설치를 진행했습니다. 기존 Minecraft·AI 계정·실제 플레이 월드에는 접속하지 않았습니다.

- 전역 Node 탐색을 제외하고 공식 Node **v24.20.0**을 내려받아 체크섬을 확인하고 설치했습니다. `npm ci --omit=dev`와 실제 모듈 불러오기에 성공했습니다. 재실행 시 로컬 구성요소를 재사용했습니다.
- 새 Minecraft 시험 폴더에 실제 Java 25 실행 환경, 공식 Fabric 설치기, Fabric API, 동료 모드를 설치했습니다. 런처 설치 항목과 버전 JSON, JAR 체크섬, 실행기 연결 설정을 확인했습니다.
- 실제 ViaProxy 다운로드·체크섬 확인을 통과했습니다.
- 실제 Codex **0.153.4** npm 설치와 실행 파일 경로 저장을 통과했습니다. 새 패키지의 `vendor/.../bin/codex.exe` 경로를 지원합니다. 계정 로그인과 설치 성공은 구분합니다.
- 모드 재설치에서 기존 JAR의 바이트 단위 백업과 다른 모드·월드·캐릭터 선택 기록의 보존을 확인했습니다. 알 수 없는 새 설정 형식은 거부하고 이전 JAR로 복구했습니다.
- 공개판의 두 캐릭터만 변경해도 설정을 저장하고 기존 다른 캐릭터의 연결 기록을 보존했습니다.

발견한 런처 표시 이름 혼동, 준비 순서에 따른 채팅 접두어 변경, Codex 실행 파일 탐색 오류를 수정하고 실제 설치 작업을 다시 통과했습니다. 마지막 3차 리허설에서는 새 계정의 실제 `Not logged in` 출력이 **로그인 필요**로 표시되는 것을 확인했습니다. 한국어 준비 안내, 새 설치, 설정 보존·복구도 통과했습니다. 회귀 시험으로 같은 오판을 막습니다.

## 실제 준비 화면과 AI 연결

내장 브라우저에서 공식 게임 이름 조회, 게임 설정 저장, 재진입 후 캐릭터별 서비스 보존, 접속할 수 없는 서버의 한국어 오류 안내를 확인했습니다. 390px와 1440px 화면을 확인했고 브라우저 오류 로그는 없었습니다. 문서의 설치 화면은 시험용 경로를 입력한 실제 화면입니다.

Codex **0.153.4**와 Claude Code **2.1.220**의 실제 계정으로 준비 화면의 연결 시험을 실행했습니다. 각각 실제 모델이 호출한 시험용 `minecraft_status`가 반환한 임의 값을 최종 응답에 포함하는지 확인했습니다. 플레이 중인 월드에 동작이나 채팅을 보내는 시험은 아닙니다.

## 패키지 확인

패키저가 허용 목록으로 파일을 복사하고, 완성 ZIP을 다시 풀어 모든 파일의 SHA-256, 필수 파일, npm/JAR 버전, 캐릭터 카탈로그·스킨 일치를 검사합니다. 개인 설정·런타임·인증·대화·개발 메모·node_modules는 설치 ZIP에 넣지 않습니다. 기존 팬 캐릭터 5인의 스킨이 공개 JAR에 없는지도 확인합니다.

릴리스에는 설치 ZIP, 단독 모드 JAR, **SHA256SUMS-v0.4.0-alpha.1.txt**를 제공합니다. 게시한 파일의 다운로드 대조 결과는 [GitHub 릴리스](https://github.com/umaia1234/makmolga/releases/tag/v0.4.0-alpha.1) 본문에서 확인할 수 있습니다.

## 남아 있는 검증 범위

일반 온라인 봇 계정의 첫 접속, 다양한 PC·런처, 모든 게임 작업의 실제 월드 결과, 장시간 자율 생존, 다른 버전에서 새 폴더로 옮기는 전체 업데이트는 검증이 남아 있습니다. Antigravity는 실계정 모델·MCP 확인 전입니다. 코드 서명과 자동 CI는 이번 검증 범위에 포함하지 않습니다.

이 릴리스는 설치·연결 경험을 정리한 **알파**입니다. 자동검사·설치 시험·모델 도구 왕복을 실제 게임 전체의 품질 보장으로 해석하지 않습니다.

설치 근거: [Fabric 공식 CLI 설치](https://wiki.fabricmc.net/install#cli_installation), [Node.js 공식 배포와 체크섬](https://nodejs.org/dist/v24.20.0/), [Codex 공식 설치 안내](https://learn.chatgpt.com/docs/codex/cli).
