# 캐릭터 채팅과 페르소나

2026-09-07, Fabric 26.2용 모드 v0.2.3 개발 빌드와 현재 실행기 소스에 적용했습니다.

## 이름 표시

업데이트한 모드에서는 `<CompanionBot> [봇] 대사` 대신 `<얀로롱> 대사`, `<지피짱> 대사`, `<도로롱> 도로!`처럼 표시합니다. 실행기는 매 메시지에 캐릭터 이름을 붙이고, 모드는 인증된 로컬 브리지가 확인한 봇 UUID에 대해서만 채팅 표시를 정리합니다. 다른 플레이어가 캐릭터 이름을 본문에 적었다고 발신자를 바꾸지 않습니다.

캐릭터를 바꾸기 전에 보낸 채팅이 늦게 도착해도 그 메시지에 기록된 원래 캐릭터 이름으로 표시합니다. Minecraft의 차단·필터·신뢰 판정이 끝난 후 표시만 바꾸므로 원본 발신자 UUID와 서명·채팅 신고 기록은 유지됩니다. 기본 플레이어 채팅 형식에 적용하며, 발신자를 확인할 수 없는 서버 알림이나 다른 플러그인의 임의 형식은 바꾸지 않습니다.

계정 이름을 바꾸며 재접속하는 방식이 아니므로 기존 봇의 인벤토리·위치는 유지합니다. 모드가 없는 클라이언트에는 `<CompanionBot> [캐릭터 이름] 대사`로 보일 수 있습니다. 변경된 계정명 표시를 보려면 Minecraft를 종료한 뒤 `Install-Update.ps1`로 v0.2.3을 설치하고 Fabric 26.2 프로필을 다시 실행합니다.

## 페르소나 유지

- 얀로롱: 자기 자신을 작은 박사로 말하며, 매 채팅에 LLM·JEPA·제파 또는 지정 밈을 포함합니다.
- 지피짱: 차분하고 다정하게 상황을 짚고, 자신의 과하게 큰 계획에 작은 농담을 붙입니다.
- 도로롱: 도로·doro의 변형과 문장부호로만 말합니다. 번역이나 행동 지문은 붙이지 않습니다.
- 젬짱: 자신 있게 나서고 짧은 놀람과 빠른 회복을 보입니다. 농담을 위해 실제 작업을 망치지 않습니다.
- 스피키: 공손한 역할 흉내 뒤에 작은 바람이나 건조한 관찰을 섞습니다. 실제로 보이는 호박에 관심을 보입니다.

명확한 이름·말투 규칙은 캐릭터별 developer instructions로 전달하고, 긴 페르소나 문서는 참고 자료로 읽습니다. 다른 캐릭터의 대화 이력이 섞이지 않도록 별도 대화를 재사용합니다. 게임 채팅과 로컬 `ctl chat` 입력은 현재 캐릭터의 대화로 들어가며, 소유자의 공통 메시지 기록은 유지합니다. 이전 공용 대화는 삭제하지 않습니다.

출력 단계에서도 도로롱의 허용 소리, 얀로롱의 줄별 필수 표현, 알려진 다른 캐릭터 이름으로 자기소개하는 오류를 보정합니다. 중간 채팅과 최종 답변이 같은 처리를 거칩니다. 자유로운 문장의 성격과 농담은 모델이 생성하므로 모든 장면의 완벽한 일관성을 보장하는 것은 아닙니다.

## 검증

Node 테스트 45개, Java 테스트 11개와 모드 빌드를 통과했습니다. 이 PC에 설치한 `companion-selector-26.2-0.2.3.jar`의 SHA-256은 `a08c9da515b04357c794a4801d8867bdf3e014ec952411ac03ed590afb006463`입니다.

Java 테스트는 다섯 캐릭터의 발신자 표시, 전송용 이름표 제거, 늦은 메시지의 원래 이름, 필터된 본문 보존과 임의 텍스트 배제를 검사했습니다. 모드를 빌드하고 설치 JAR의 해시를 확인했습니다. 실제 사용자 화면에서의 v0.2.3 채팅 표시는 게임 재실행 후 확인할 항목입니다.

Node 테스트는 캐릭터별 대화 분리·재사용·재시작, 이전 대화의 늦은 메시지 차단, 각 전송 줄의 이름과 말투, 자기소개 이름 보정을 검사했습니다. 업데이트 도중 기존의 위험 중지 상태가 자동 해제되지 않도록 정상 종료 시 중지 이유를 보존합니다.

게임과 분리된 실제 Codex 대사 점검에서 다섯 캐릭터 모두 자신의 말투로 응답했습니다. 도로롱은 `도로! 도로오오… doro!`, 얀로롱은 자신을 LLM·JEPA를 좋아하는 작은 박사로 소개했고, 나머지 셋도 자신의 이름으로 응답했습니다. 이 점검은 가상의 목재 정리 장면이며 실제 게임 작업이나 사용자 채팅을 만들지 않았습니다.
