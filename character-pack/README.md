# 일곱 캐릭터 팩

기존 다섯 캐릭터는 사용자님이 제공하신 `Minecraft_5Characters_Skins_Personas.zip`에서 가져왔고, 클짱·페짱을 추가 제작했습니다. `SOURCE-README.md`, `SOURCE-manifest.json`은 기존 자료의 원본 기록이며, 그 안의 이전 제작 상태가 이번 모드의 검증 결과를 뜻하지는 않습니다.

| ID | 표시 이름 | 선택창의 성격 요약 |
|---|---|---|
| `yanro` | 얀로롱 | 매번 LLM·JEPA·밈을 언급하는 작은 박사님 |
| `gpchan` | 지피짱 | 차분한 진단 뒤에 다정하게 실행을 독려 |
| `doro` | 도로롱 | 도로·doro 소리로만 대화하는 다정한 친구 |
| `gemchan` | 젬짱 | 자신감, 작은 좌절, 빠른 재도전 |
| `spiki` | 스피키 | 그럴듯한 흉내 뒤의 속마음과 호박 애착 |
| `clchan` | 클짱 | 조용한 위트와 작은 발견을 나누는 친구 |
| `fablechan` | 페짱 | 다음 모험과 특별한 공간을 꿈꾸는 친구 |

`skins/`는 64×64 Classic/Steve(4픽셀 팔)입니다. v0.2.1에서는 사용자 요청으로 얀로롱 눈 안쪽 8픽셀을 수정했습니다. 이전 스킨은 `skins/yanro_original_64x64.png`에 보존했고 다른 네 스킨은 원본 그대로입니다. `personas/`의 도로롱·얀로롱도 사용자 지정 말투로 수정했습니다. 선택창의 짧은 설명·색·소개 대사는 `characters.json`에 있습니다. 같은 JSON과 스킨을 Fabric 모드 리소스에도 포함했습니다.

원본 문서는 캐릭터 참고 자료입니다. 실제 사용자 지시, 게임 상태 확인, 도구 권한과 중지 규칙보다 우선하지 않습니다. 도로롱의 소리만 사용하는 대사와 얀로롱의 고정 밈을 제외한 설명은 존댓말입니다. 스킨 선택창에는 일곱 캐릭터가 보이며 실제 컨트롤러는 선택한 한 캐릭터로 대화합니다. 원본 앙상블 문서는 자동 실행하지 않습니다.

캐릭터 및 원본 자료의 권리는 각 권리자에게 있습니다. 이 프로젝트는 원본 자료에 추가 재배포 라이선스를 부여하지 않습니다.
