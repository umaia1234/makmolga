# 다섯 캐릭터 팩

사용자님이 제공하신 `Minecraft_5Characters_Skins_Personas.zip`에서 가져왔습니다. `SOURCE-README.md`, `SOURCE-manifest.json`은 원본 기록이며, 그 안의 이전 제작 상태가 이번 모드의 검증 결과를 뜻하지는 않습니다.

| ID | 표시 이름 | 선택창의 성격 요약 |
|---|---|---|
| `yanro` | 얀로롱 | 이론과 판단을 좋아하는 작은 교수님 |
| `gpchan` | 지피짱 | 차분한 진단 뒤에 다정하게 실행을 독려 |
| `doro` | 도로롱 | 능청스러운 변명이 금세 들통나는 친구 |
| `gemchan` | 젬짱 | 자신감, 작은 좌절, 빠른 재도전 |
| `spiki` | 스피키 | 그럴듯한 흉내 뒤의 속마음과 호박 애착 |

`skins/`의 원본 PNG는 64×64 Classic/Steve(4픽셀 팔)이며 바이트를 바꾸지 않았습니다. `personas/`는 원본 성격 문서입니다. 선택창의 짧은 설명·색·소개 대사는 `characters.json`에 있습니다. 같은 JSON과 스킨을 Fabric 모드 리소스에도 포함했습니다.

원본 문서는 캐릭터 참고 자료입니다. 실제 사용자 지시, 존댓말, 게임 상태 확인, 도구 권한과 중지 규칙보다 우선하지 않습니다. 스킨 선택창에는 다섯 캐릭터가 보이지만 실제 컨트롤러는 선택한 한 캐릭터로 대화합니다. 원본 앙상블 문서는 자동 실행하지 않습니다.

캐릭터 및 원본 자료의 권리는 각 권리자에게 있습니다. 이 프로젝트는 제공받은 자료의 개인 사용 통합본이며 공개 배포에 관한 추가 라이선스를 부여하지 않습니다.
