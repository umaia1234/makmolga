# 마크 스킨 + 대유쾌마운틴 페르소나 5인 세트

얀로롱·지피짱·도로롱·젬짱·스피키의 스킨과 한국어 LLM 연기용 프롬프트입니다. 젬짱은 새 참고 이미지의 흰 블라우스, 초록 목 리본, 남색 치마, 검은 스타킹과 신발을 입힌 버전입니다.

## 바로 사용하기

- **마크 스킨:** `skins/`에서 해당 PNG를 골라 Java 런처의 스킨 메뉴에서 **클래식(Classic / Steve)** 모델로 적용합니다. 모두 64×64이며 팔 너비는 4픽셀입니다.
- **한 캐릭터와 대화:** `personas/`의 해당 Markdown 파일 전체를 LLM의 시스템 프롬프트 또는 새 대화 첫 메시지에 붙여 넣으세요. 그다음 상황을 말하면 됩니다.
- **다섯 캐릭터가 함께 출연:** `ensemble_prompt.md` 전체를 붙여 넣으세요. 예: `셋이 집을 고치는 장면. 젬짱이 설치한 문이 천장에 붙어 있다.`
- **프로그램에서 사용:** `personas.json`의 `characters`에서 원하는 `id`를 고르고 `system_prompt` 값을 읽으면 됩니다. JSON과 Markdown은 같은 내용을 담습니다.

| 캐릭터 | PNG | 개별 프롬프트 | 말투의 중심 |
| --- | --- | --- | --- |
| 얀로롱 | skins/yanro_classic_64x64.png | personas/yanro.md | 이론과 판정으로 시작해서 자기변호가 새어 나옴 |
| 지피짱 | skins/gpchan_classic_64x64.png | personas/gpchan.md | 정확하고 담담한 진단에서 과잉 공감·실행 독촉으로 전환 |
| 도로롱 | skins/doro_classic_64x64.png | personas/doro.md | 짧고 뻔뻔한 면피, 표정과 행동으로 들통남 |
| 젬짱 | skins/gemchan_classic_64x64.png | personas/gemchan.md | 자신감이 치솟다가 오류 하나에 추락하고 다시 부활 |
| 스피키 | skins/spiki_classic_64x64.png | personas/spiki.md | 그럴듯한 흉내에서 튀어나오는 본심·독설, 호박 친구 애착 |

## 대화를 시작할 상황 예시

```text
캐릭터: 젬짱
상황: 네가 자랑하던 자동문이 플레이어를 밖에 가둬 버렸다.
플레이어: 문 좀 열어 봐.
2문장으로 대답해. 아직 문을 실제로 연 것은 아니다.
```

```text
캐릭터: 스피키
상황: 얀로롱의 강의를 흉내 내다 들켰다.
플레이어: 그 안경 어디서 났어?
짧은 행동 묘사 하나와 대사로 답해.
```

각 페르소나에는 장난을 치는 방법뿐 아니라 과사용하면 재미가 없어지는 표현, 진지한 장면으로 전환하는 기준, 상황별 창작 대사가 들어 있습니다. 웃음의 강도는 대화 상황과 사용하는 LLM에 따라 달라집니다.

## 무엇을 조사했나

서브에이전트 3명이 캐릭터별로 사용자 첨부 디시콘과 웹의 제작글·용례·소개 자료를 조사했습니다. `research/`에는 직접 확인한 문구와 외형, 링크, 확인이 어려웠던 부분을 적었습니다. **원본에서 관찰한 특징과 이 팩에서 새로 만든 연기 설정·예시 대사를 구분했습니다.** 모든 대사를 공식 설정으로 취급하는 자료집은 아닙니다.

`examples/audition.md`에는 같은 사건에 다섯 캐릭터가 어떻게 다르게 반응하는지 비교할 대사를 담았습니다. 캐릭터별 프롬프트와 합본은 채팅용 텍스트이며, 마크 NPC나 LLM 연결 모드는 포함하지 않습니다.

## 파일 확인

`previews/`는 완성된 스킨 PNG를 기본 플레이어 형태에 입힌 앞뒤 미리보기입니다. `manifest.json`은 파일 해시와 스킨 규격 검사 결과입니다. 실제 게임 접속 시험은 수행하지 않았습니다.

젬짱 의상 원화는 내장 imagegen으로 편집했고, `production/gemchan_outfit_prompt.txt`에 프롬프트를 남겼습니다. 실제 업로드 파일은 원화를 스킨 좌표에 맞춰 변환한 `skins/gemchan_classic_64x64.png`입니다.
